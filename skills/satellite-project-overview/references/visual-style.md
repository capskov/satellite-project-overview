# 已认可的视觉表达

默认参数源自用户认可的工程方案插图；公开示例为合成数据，只用于展示样式。

## 视觉层次

- 深蓝标题，白色背景；左侧短蓝色竖线用于标题强调，可按项目改变。
- 卫星影像保持真实地貌和路网。轻度降饱和/调亮暗即可，不滤成看不清的灰底，也不人为重绘建筑。
- 主管推荐蓝色 `#087fce`；外加白色衬边。暗色细外缘可选，防止浅色道路上白边丢失。先描外缘，再白边，再蓝线；转折圆润，保持连续。
- 接驳点青绿 `#008b83`，过河点暖橙 `#d48a28`，终点蓝色，园区位置淡紫 `#a568d2`，河道浅青绿 `#25c8ad`。颜色可根据项目语义调整，不把某颜色固定为工程规范。
- 大区域透明度约25%～40%起步，边界比填色略清楚；让底图仍可辨。小节点用白色外圈。
- 线粗按目标插入尺寸选择。参考4800px宽画布，蓝线约19px、白边约32px；这些是视觉比例示例，不是管径或真实宽度。可用细白色三角/箭头标方向。

## 白框和标注

先确定标题、副说明的文字与字号，然后按最长一行的实际字宽，加左右适当边距确定框宽。框高按两行实际高度和行间距确定。不要统一把所有白框拉到同一长度，更不能出现文字只占左半边的长白条。

单行园区名采用单行紧凑底；较长交水点名称可保留较宽框。字号不按画布宽度的固定百分比机械套用：参考图4800px画布上普通标题68px、副文56px，单行园区名76px。最终看目标纸面大小。

框与引线成组考虑。把E点上方区域用于园区展示时，将终点和邻近过河说明移到下方，不把框压在接入位置上。白框缩短后重新定位引线终点，不能让线停在空处；尽量不要引线横穿主管。不要求所有标签同侧。

## 信息裁减

保留：图名、起终点关系、路线、必要管径/概略长度、重要穿越、图例、园区/服务对象位置。按用途选择，不强制全部出现。

省略：密集节点编号、微小阀件、尺寸、高程、纵断、施工结构、工程量细表和与认路无关的辅助线。有必要时保留关键节点编号，帮助读者回到设计图。

默认无比例尺。图例中区域示意与点位区分；园区大圆点不是边界。用少量图面说明表达“概化示意、详细定位以设计图为准”，不把制作过程、程序名、调试信息写进成品。

## 输出复查

检查原图和缩小版，尤其是终点周围、说明框空白、主管连续性、颜色区分、遮挡及文字是否溢出。PPT通常用16:9或按实际版心；A4附件常用宽幅插图，参考4800×2520只是一种比例。

PNG按插入宽度给足像素；缩放到180mm宽时，4800px已有充分余量，不把DPI标签当作实际清晰度。SVG保留背景影像嵌入、矢量线面与文字；跨机器字体需要接收方可用，不能仅凭本机显示宣称字形完全一致。
