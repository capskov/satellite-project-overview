# 卫星总图与方案插图

目标是缩小后仍一眼看懂“从哪里来、沿哪里走、接到哪里”。优先使用 CAD/GIS 的真实线路作骨架，在图外完成信息筛选和排版；无需为了插图样式修改正式设计。

先看 [匿名合成示例](assets/example-overview.png)，再读 [样式与排版](references/visual-style.md)。示例为虚构数据，仅用于理解样式和工具，不是实际工程地图。

## 默认效果与输入

用户已明确将此效果作为以后未另行指定时的默认选择。默认输入为原始DWG＋卫星底图＋用户指出的桥梁、河流、铁路、园区等要素；不要求用户每次再选配色或字号。采用 [默认样式参数](assets/default-style.json)，根据输出画布同比例调整，保留已认可的视觉层次。桥梁、铁路等按本次资料补充，用次级颜色和符号表达，不盖过主管，也不把它们全画成水体填色。

底座是可配合的数据/编辑工具，不是插图排版的必经后端：CAD读写遵循用户要求走底座；已有可靠坐标或导出几何时，独立排版无需再强行写回CAD。最终必须实际渲染、查看缩小效果，再交付PNG/SVG及所需PDF/PPT。

默认视觉参数保存在 [样式配置](assets/default-style.json)，并提供可运行的匿名合成示例。新工程应重新判读和排列要素。

## 选择交付方式

默认推荐 **CAD/GIS确认真实位置＋独立插图排版**。需要可编辑DWG时同步整理CAD副本；主要用于PPT/A4附件时，优先提供高清PNG和可编辑SVG，按需增加PDF。用户指定全部在CAD完成时尊重选择，并如实说明原生样式及出图能力的限制。

“PPT总图”不自动意味着必须生成整套PPT。若用户要可编辑幻灯片或明确要求PPTX，再使用当前演示文稿技能，按可用能力提供原生对象或清楚说明底图、线条和文字的编辑范围；不能把一张贴图称为全部元素可编辑。

## 从工程资料到插图

1. **先确认信息关系。** 找出实际起点/水源侧接驳点、终点/交水点、总体走向、显著转折及重要过河/穿越。管径、长度和名称取自本项目资料或用户确认。区分水源系统、水源地、工程接驳点、交水计量点；按用户最新命名落图，不从文件名编造连接关系。
2. **读取位置和影像配准。** CAD读写优先使用当前环境中用户指定的底座；相关CAD操作优先调用可用技能，按当前用户要求处理接口错误。读取真实会话、对象几何及影像插入点、U/V轴、尺寸和路径；代理保存图形只作已覆盖范围的图面依据。坐标和底座经验见 [数据与工具衔接](references/data-and-tools.md)。不把旧项目句柄、目录或版本当作当前输入。
3. **由Agent概化。** 保留影响读者认路的弯曲、沿路/沿河关系和接入方向；合并小折线和细密井点，隐藏尺寸、高程、施工详图、密集井号。概化不能跨到另一条路或跳过重要折返。长线保持连续，箭头沿真实供水方向；方向未知时省略箭头。
4. **先看图再安排信息。** 园区位置可用半透明大圆点或区域表示，区别于精确接驳小点；没有地块依据时标成位置示意。把园区名称放在区域附近，避开终点及其上方需要观察的区域。说明框依据实际文字收紧，少字不得保留长条白底。引线明确指向，避免遮住主管和关键点。
5. **河道按影像判读。** 用户要求时，对照原始影像及指定的Google等地图，核对同一桥涵、道路和弯曲。轮廓取自本项目影像，半透明面用另一颜色。看不清处概化并用“河道范围（示意）”；不能将植被、旱滩、整个河槽一概声称为实测水面，也不能凭两处过河点画一条想象的河。无需自动抓取远程影像或替换原始底图。
6. **小图适配。** 保持卫星底图可辨，适度降饱和或压低对比；白色衬边＋蓝色粗线突出主管。只标少量重点。默认不放比例尺，适合用户缩放插入附件；明确要求有尺度表达时再加入并核对。北箭头仅在方向有依据时保留，不随意把画面上方称为真北。
7. **看最终导出结果。** 先看整图，确认线路连续、节点和引线准确；再按目标插入宽度检查文字、白框空隙、接入点周边、河道叠合与透明度。普通中文先以最终纸面约2.5～3.5mm为参考，标题和重点可更大，实际以缩放后的可读性为准。修复后同步PNG/SVG/PDF，保留上一版。只完成插图时，不声称CAD副本或PPT已同步完成。

## 可复用工具

`scripts/render_overview.py` 根据显式JSON图元输出PNG和SVG：背景、WCS/原图像素/画布像素定位、白边连续线路、半透明河道与园区、按文字收紧的说明框。它只执行已由Agent选择的坐标和排列，不识别河岸、不判断方案。

输入与运行方式见 [绘图配置](references/render-config.md)。先用工具加载器定位Python和Pillow；需要PDF、PPT时使用对应当前技能和运行环境，不硬编码这台机器的缓存版本。不携带或安装用户字体文件。

## 本轮沉淀的边界

- 样式已由用户认可；通用绘图工具需随实际项目继续看图调整，不能保证每个项目自动排版。
- 当前公开仓库使用合成示例；任何真实工程成果的分享应遵循项目及用户的授权。
- 不为做插图而开发新的CAD底座功能。遇到基础能力缺口，记录具体操作、结果和替代路线；未知写入查询原请求，不重放或改后端绕过。
